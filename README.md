# Urbania Welfare Community Center — Donation Website

A charity and donation website for the Urbania Welfare Community Center. It's a front-end only, multi-page site covering the center's work, events and ways to support it, including a donation page with bank details.

## Live Demo

https://hackathon-donation.netlify.app/

## Features

- Multi-page site: Home, About, Services, Events, Education, Funeral, Gallery, Volunteer, Donation, Registration, Contact and Login pages
- Donation page with a bank details page for direct transfers
- Information pages for the center's services, education and funeral support work
- Volunteer and registration pages

## Tech Stack

- Plain HTML, CSS and JavaScript
- No backend, no build tools

## Getting Started

No install or build step is needed. Just open the home page:

```bash
# open this file in a browser
index.html
```

Or host the folder on any static host (Netlify, Vercel, GitHub Pages, etc.).

## Notes

Front-end only — the forms (donation, registration, login, contact) are front-end pages and don't submit to a server.

Not to be confused with Blockchain-Donation-System-main, which is a separate blockchain-based donation project.
